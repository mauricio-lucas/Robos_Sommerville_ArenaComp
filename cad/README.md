# Carcaças 3D (STLs)

Colocar aqui os arquivos `.stl` escolhidos + o link da fonte.

## Onde buscar
- Thingiverse: "mini sumo chassis", "mini sumo robot"
- Printables: "sumo robot 1kg", "line follower robot chassis"
- Buscadores agregadores: yeggi.com, stlfinder.com

## Critérios de escolha
- Fotos de impressão real no post do modelo
- Furos de fixação compatíveis com motor TT (eixo 5,4mm com rebaixos)
- Sumô: chassi baixo, lâmina frontal rasa, espço para 6×AA + ponte H
- Material: PETG (sumô) / PLA (rampa); preenchimento 40–60%
- ⚠️ Enviar para imprimir até o dia 3 do cronograma
